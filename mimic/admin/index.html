Voice moderation

Review, approve and take down voices submitted to Mimic's Public library. This page is only a bookmark. The dashboard itself runs on the backend — approving a voice writes to a database, and GitHub Pages serves static files only, so it cannot proxy.

The password is the only thing protecting the dashboard. This file is served by GitHub Pages from a public repository and it contains the dashboard's address in plain HTML, so treat that address as published, not secret — noindex keeps it out of search results, which is not the same as keeping it private. Anything that matters has to rest on the password.

One-time setup on the backend. You type the password; nobody else sees it, and only its hash is stored: 

  1. ssh -i ~/.ssh/oracle_speedtest.key ubuntu@64.181.251.135
  2. caddy hash-password
  3. sudo /opt/mimic/enable-dashboard.sh '<the hash it printed>'

There's also always the local route, which needs no password at all because it never leaves your machine: 

ssh -i ~/.ssh/oracle_speedtest.key -L 8080:localhost:7475 ubuntu@64.181.251.135

…then open localhost:8080/admin/.

Before you approve anything

Listen to it first. The dashboard can't play a voice — synthesising one needs the full converter, which doesn't fit on the backend — so render the pending queue locally and play it: 

Scripts/catalog.sh review

A name and a description can't tell you whether a clone is of someone who agreed to it. That's the whole reason a person reviews these.
