Voice moderation

Review, approve and take down voices submitted to Mimic's Public library. This page is only a bookmark. The dashboard itself runs on the backend — approving a voice writes to a database, and GitHub Pages serves static files only, so it cannot proxy. Keep this page to yourself: the link below is the dashboard's unguessable address, which is half of what protects it.

Open the dashboard Username greg · your moderator password →

If the link 404s, public access isn't switched on yet

One-time setup on the backend. You type the password; nobody else sees it, and only its hash is stored: 

ssh -i ~/.ssh/oracle_speedtest.key ubuntu@64.181.251.135
caddy hash-password
sudo /opt/mimic/enable-dashboard.sh '<the hash it printed>'

There's also always the local route, which needs no password at all because it never leaves your machine: 

ssh -i ~/.ssh/oracle_speedtest.key -L 8080:localhost:7475 ubuntu@64.181.251.135

…then open localhost:8080/admin/.

Before you approve anything

Listen to it first. The dashboard can't play a voice — synthesising one needs the full converter, which doesn't fit on the backend — so render the pending queue locally and play it: 

Scripts/catalog.sh review

A name and a description can't tell you whether a clone is of someone who agreed to it. That's the whole reason a person reviews these.
